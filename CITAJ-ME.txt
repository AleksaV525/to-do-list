TO-DO - instalacija na telefon

GitHub Pages (ako vec imas repozitorijum sa prethodnom verzijom):
1. Otvori repozitorijum na github.com -> Add file -> Upload files.
2. Prevuci SADRZAJ ovog foldera (index.html, sw.js, manifest.webmanifest i sve .png), ne sam folder.
   GitHub ce zameniti stare fajlove. Klikni Commit changes.
3. Posle minut-dva otvori isti link. Nova verzija se ucita pri drugom otvaranju.
   Ako je stara aplikacija vec na pocetnom ekranu, obrisi je i instaliraj ponovo da dobije novo ime i ikonicu.

Novi repozitorijum:
1. New repository -> Public -> Create.
2. Uploading an existing file -> prevuci sadrzaj foldera -> Commit.
3. Settings -> Pages -> Branch: main, folder: / (root) -> Save.
4. Link je https://TVOJE-IME.github.io/NAZIV-REPOZITORIJUMA/

Instalacija:
Android (Chrome): meni -> Instaliraj aplikaciju.
iPhone (Safari): Podeli -> Dodaj na pocetni ekran.

Napomene:
- Podaci su samo na tom uredjaju. U Podesavanjima postoji "Preuzmi" kopiju i "Vrati iz fajla".
- Zadaci iz stare verzije (Meridian) se prenose automatski ako je otvoris na istom linku. Primeri se brisu.
- Podsetnici stizu dok je aplikacija otvorena ili u pozadini. Kad je potpuno zatvorena, nema servera koji bi ih poslao.
- Brzo dodavanje: "Sastanak petak 14:30-15:30 #Posao p1 @hitno" ili "Trening svake nedelje 18:00 1h"
  p1 hitno, p2 visok, p3 srednji, p4 nizak.
